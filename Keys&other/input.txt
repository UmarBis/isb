Лабораторная работа №3 "Построение гибридной криптосистемы"

В данной лабораторной работе реализована гибридная криптосистема, сочетающая в себе преимущества симметричных и асимметричных алгоритмов шифрования. Симметричные алгоритмы работают быстрее асимметричных и ими удобно шифровать большие объемы информации. Асимметричные алгоритмы не требуют наличия секретного канала для передачи ключа.

Использованные алгоритмы:
1. ChaCha20 - симметричный потоковый шифр, разработанный Даниэлем Берштейном.
   - Длина ключа: 256 бит
   - Длина nonce: 128 бит
   - Высокая производительность на программных реализациях
   - Устойчивость к атакам по времени

2. RSA - асимметричный алгоритм шифрования
   - Длина ключа: 2048 бит
   - Используется для шифрования симметричного ключа
   - Основан на сложности факторизации больших чисел
   - Широко применяется в современных криптосистемах

Принцип работы гибридной криптосистемы:
1. Генерация ключей:
   - Создание симметричного ключа для ChaCha20
   - Генерация пары ключей RSA
   - Шифрование симметричного ключа с помощью открытого ключа RSA

2. Шифрование данных:
   - Расшифровка симметричного ключа с помощью закрытого ключа RSA
   - Шифрование исходного текста с помощью ChaCha20

3. Дешифрование данных:
   - Расшифровка симметричного ключа с помощью закрытого ключа RSA
   - Дешифрование текста с помощью ChaCha20

Тестирование системы, весенний семестр 2024 года.
Специальность "Информационная безопасность автоматизированных систем"
